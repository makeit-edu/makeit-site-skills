02

작업 기준을 알려주는 도우미

메킷 스킬을 준비해요.

스킬은 Codex가 참고하는 작업 지침입니다. WordPress에 설치하는 플러그인과는 다릅니다.

메킷 스킬Codex에서 사용
내 플러그인 ZIPWordPress에 설치

아래 문장을 복사해 Codex에 보내세요. 설치 과정의 권한 요청은 내용을 읽고 확인합니다.

$skill-installer를 사용해서 https://github.com/makeit-edu/makeit-site-skills/tree/v0.1.0/skills/makeit-site-improve 의 스킬을 설치해줘. 같은 이름이 이미 있으면 덮어쓰지 말고 알려줘. 설치 후 실제 스킬 이름과 읽을 수 있는지 확인해줘.

설치가 안 되거나 스킬이 안 보여요.

오류 화면을 Codex에 보여주고 설치 위치와 네트워크 접근을 확인해 달라고 하세요. 설치 경로를 확인했는데도 발견되지 않으면 앱을 다시 시작해 보세요. 설치 성공과 실제 사용 가능 여부를 따로 확인합니다.

공개 설치 검증 범위는 검증 기록에 있습니다. Windows 첫 설치는 별도 확인이 필요합니다.

03

여기부터 내 선택

바꾸고 싶은 것을 말해요.

처음에는 관련 글 카드 하나만 바꿉니다. 다른 기능은 그대로 둡니다.

관련 글을 사진 카드로 바꿔줘.
기존 출력 위치를 확인하고,
원본을 보관한 뒤 작업본을 수정할게요.
대화 모형 · 실제 응답은 작업 상황에 따라 달라집니다.

메킷 사이트 메이커를 사용해 이 ZIP을 살펴봐줘. 원본은 보관하고 작업본을 만들어줘. 기존 관련 글을 사진 카드로 바꾸고 컴퓨터에서는 3열, 휴대폰에서는 1열로 보여줘. 이미 있는 관련 글을 중복 추가하지 말고, 사진이나 관련 글이 없는 경우도 처리해줘. 라이선스·광고·초기화 기능은 바꾸지 마.

다음에는 내 방식으로.

Codex가 바꿀 곳을 설명하면 내 의도와 맞는지 읽어보세요. 사이트 전체 개편이나 외부 도구 비용이 추가되면 범위를 먼저 정합니다.
04

“다 됐어요”보다 화면 확인

직접 눌러보고, 작게도 봐요.

먼저 연습용 WordPress에서 확인합니다. 테스트 사이트가 없다면 Codex에게 준비 방법을 물어보세요. 운영 사이트를 연습장으로 쓰지 않습니다.

① 원하는 모습인가요?

바꾸기로 한 부분만 달라졌는지 봅니다.

② 링크가 열리나요?

카드를 눌러 실제 글로 가는지 확인합니다.

③ 휴대폰도 괜찮나요?

가로 넘침·긴 제목·사진 없는 글을 확인합니다.

④ 기존 기능은요?

본문·메뉴·검색 관련 설정을 함께 확인합니다.

이번 변경을 실제 테스트 WordPress와 브라우저에서 확인해줘. 카드 중복, 잘못된 링크, 사진 없는 글, 긴 제목, 휴대폰 화면, 기존 검색 관련 출력이 달라졌는지 점검해줘. 확인하지 못한 것은 통과라고 하지 말고 따로 알려줘.

PHP 문법 검사만 통과했다면 아직 WordPress 작동 확인이 끝난 것이 아닙니다.
05

내 결과물 남기기

설치 파일과 복구 방법을 받아요.

내 수정본 ZIP변경 내용검사 결과이전 버전 복구법

확인한 작업본을 WordPress 설치용 ZIP으로 만들어줘. 키·수강 코드·로그·DB·원본 백업은 넣지 마. 바꾼 내용과 검사 결과, 아직 확인하지 못한 점, 이전 버전으로 되돌리는 방법을 함께 정리해줘. 원본은 덮어쓰지 마.

파일 복구와 글·사진·설정 복구는 다릅니다. ‘초기화’ 버튼을 누르는 것은 되돌리기가 아닙니다.

06

연습이 끝난 다음

내 WordPress에 적용해요.

운영 사이트와 백업·복구 방법을 확인한 뒤 진행합니다. 교체형 수정판인지 별도 추가 플러그인인지 먼저 확인하세요.

  1. 현재 사이트의 파일·DB를 백업합니다.
  2. 관리자 → 플러그인 → 새로 추가 → 플러그인 업로드를 엽니다.
  3. Codex가 만든 플러그인 ZIP을 선택합니다.
  4. 기존판 교체 여부를 확인하고 설치·활성화합니다.
  5. 캐시 영향을 확인하고 실제 글·모바일 화면을 다시 봅니다.
교체형 수정판과 원본을 동시에 활성화하지 마세요. 에러로 관리자 화면이 안 열릴 때 사용할 호스팅 복구 경로도 먼저 확보합니다.

WordPress 연습 플러그인 ZIP 받기

연습 사이트에 설치한 뒤, 같은 카테고리의 공개 글을 두 개 이상 준비하세요. 한 글의 단축코드 블록에 [makeit_related_lab]를 넣습니다. 기존 관련 글을 자동 대체하지는 않습니다.

삭제할 때는 해당 단축코드 블록을 지운 뒤 비활성화하세요. 글과 사진은 지우지 않습니다.

SEO·GEO 스킬이면 노출이나 승인이 보장되나요?

아닙니다. 기술적 오류와 읽기 불편한 구조를 점검하는 도우미입니다. 검색 순위·AI 인용·애드센스 승인 결과를 보장하지 않습니다. 공식 근거 보기

스킬 사용에 별도 키가 필요한가요?

이 스킬 자체는 별도 API 키나 유료 SEO 서비스가 필요하지 않습니다. Codex 이용 조건은 계정에 따릅니다. 추가 도구·서비스가 필요한 작업은 비용과 설치 필요성을 먼저 확인합니다.

강사·담당자 브리핑 요약

3주차 목표는 학생이 자신의 기능을 Codex로 만들어 보는 것입니다. 공통 실습 → 개인화 → 실제 확인 → ZIP·복구 → 운영 적용으로 진행합니다. 첫 사용자 완주·Windows 환경은 별도 검증 항목이며, 검증 기록의 범위를 넘어 성공을 주장하지 않습니다.
