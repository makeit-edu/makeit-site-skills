코덱스로
내 플러그인 만들기

바꾸고 싶은 것을 말하면 코덱스가 작업본을 수정합니다.
화면을 확인하고 내 워드프레스에 적용해 봅니다.

먼저 챙길 것

  • 코덱스를 사용할 수 있는 컴퓨터 — 작업 폴더를 열고 파일을 수정할 수 있어야 합니다
  • 강의에서 받은 메킷애센 플러그인 ZIP — 원본은 그대로 보관합니다
  • 새 작업 폴더 — 이번에는 1·2주차 폴더와 따로 만듭니다
  • 연습용 워드프레스 — 화면과 작동을 확인할 곳입니다
  • 내가 바꾸고 싶은 기능이나 모양 한 가지

안내서는 휴대폰으로 봐도 됩니다. 파일 수정 실습은 컴퓨터에서 진행하세요.

2주차와 달라요 — 새 폴더에서 시작이번에는 정해진 글쓰기 자동화를 실행하는 것이 아니라 플러그인을 직접 바꿉니다. 1·2주차 폴더 안의 프로그램과 설정은 건드리지 않습니다.
1

새 폴더 만들고 코덱스로 열기

컴퓨터에 내 플러그인 연습 폴더를 만듭니다. 코덱스에서 이 폴더를 작업 폴더로 고르세요.

작업 폴더 · 설명용 그림
내 플러그인 연습이번 실습에서 새로 만든 폴더
여기까지 확인코덱스의 작업 폴더 이름이 ‘내 플러그인 연습’인지 보세요.

3

메킷 스킬 설치 — 이 문장

아래 문장을 복사해서 코덱스 채팅창에 붙여넣으세요.

$skill-installer를 사용해서 https://github.com/makeit-edu/makeit-site-skills/tree/v0.1.0/skills/makeit-site-improve 의 스킬을 설치해줘. 같은 이름이 이미 있으면 덮어쓰지 말고 알려줘. 설치 후 실제 스킬 이름과 읽을 수 있는지 확인해줘.

스킬은 ‘코덱스의 작업 지침’입니다검색에 필요한 구조, 기존 기능 보호, 변경 후 확인 기준을 알려줍니다. 워드프레스에 설치하는 플러그인과는 다릅니다. 스킬 자체에는 별도 API 키가 필요하지 않습니다.
설치를 진행할지 물으면대상이 위 메킷 저장소인지 읽어보고 진행해라고 답하세요. 다른 도구 설치나 비용이 나오면 무엇이 필요한지 먼저 확인합니다.

확인할 것: 코덱스가 makeit-site-improve 스킬을 찾고 읽을 수 있어야 합니다.

4

바꾸고 싶은 것 말하기

처음에는 글 아래의 관련 글을 사진 카드로 바꿔봅니다. 아래 문장을 그대로 보내세요.

메킷 사이트 메이커를 사용해 이 폴더의 플러그인 ZIP을 살펴봐줘. 원본은 보관하고 작업본을 만들어줘. 기존 관련 글을 사진 카드로 바꾸고 컴퓨터에서는 3열, 휴대폰에서는 1열로 보여줘. 같은 기능을 중복 추가하지 말고, 사진이나 관련 글이 없는 경우도 처리해줘. 라이선스·광고·초기화 기능은 바꾸지 마.

코덱스 대화 · 설명용 예시

관련 글을 사진 카드로 바꿔줘.

기존 관련 글이 나오는 곳을 확인하고,
원본과 별도의 작업본을 수정할게요.

실제 응답과 추가 질문은 파일과 환경에 따라 달라집니다.
다른 기능까지 바꾼다고 하면이번에는 관련 글만 바꿔줘라고 말하세요. 파일을 읽거나 수정할 권한을 요청하면 대상 폴더를 확인합니다.
5

연습 사이트에서 직접 확인

코덱스가 다 만들었다고 하면 연습용 워드프레스에서 화면과 작동을 확인합니다. 아래는 실제 로컬 시험 화면입니다.

검증용 글·이미지를 사용한 화면입니다. 사진을 누르면 크게 볼 수 있습니다.

  • 카드를 누르면 맞는 글이 열리나요?
  • 휴대폰에서는 한 줄에 하나씩 보이나요?
  • 사진이 없는 글과 긴 제목도 괜찮나요?
  • 기존 본문·메뉴와 관련 글이 중복되거나 사라지지 않았나요?

이번 변경을 연습용 WordPress와 브라우저에서 확인해줘. 관련 글 중복, 링크, 사진 없는 글, 긴 제목, 모바일 화면, 기존 검색 관련 출력을 점검해줘. 실제 확인한 것과 못 확인한 것을 나눠서 알려줘. 운영 사이트에는 아직 적용하지 마.

연습 사이트가 아직 없다면운영 사이트를 건드리지 않고 연습할 환경을 준비하는 방법부터 알려줘라고 말하세요. 준비가 안 되면 화면 검증은 아직 끝난 것이 아닙니다.
“문법 검사 통과”만으로 끝이 아닙니다워드프레스에서 실제로 켜지고, 원하는 화면이 나오는지 확인해야 합니다.
6

이번에는 내 방식으로 바꾸기

공통 실습이 되면 내가 원하는 변화 한 가지를 더 말해보세요. 강사의 문장을 그대로 따라 하는 데서 끝나지 않습니다.

글자카드 제목을 조금 더 크게 해줘.
색상카드 배경을 연한 초록색으로 바꿔줘.
배치컴퓨터에서는 한 줄에 두 개만 보여줘.

이 입력란은 문장만 만듭니다. 복사해서 코덱스에 보내야 수정됩니다.

바꾼 뒤에는 한 번 더5번처럼 화면과 링크를 다시 확인하세요. 원치 않는 부분이 바뀌면 그 부분을 정확히 말하면 됩니다.
7

내 설치 ZIP과 복구 방법 받기

마음에 들고 검사도 끝났다면 워드프레스에 설치할 ZIP을 만들어 달라고 하세요.

확인한 작업본을 WordPress 설치용 ZIP으로 만들어줘. 원본은 덮어쓰지 마. 개인 키·비밀번호·수강생 설정 파일·DB·로그·백업은 넣지 말고, 기존 라이선스 기능은 유지해줘. 바꾼 내용, 검사 결과, 못 확인한 점, 원본으로 되돌리는 방법도 함께 정리해줘. 공개 배포는 하지 마.

받을 것은 네 가지내 수정본 ZIP · 변경 내용 · 검사 결과 · 이전 버전으로 돌아가는 방법.
‘초기화’는 되돌리기가 아닙니다초기화하면 글이나 설정이 지워질 수 있습니다. 원래대로 돌아갈 때는 보관한 원본과 백업을 사용합니다.
8

백업하고 내 워드프레스에 적용

연습 사이트에서 확인한 뒤 진행합니다. 운영 사이트의 파일·DB를 백업하고, 문제가 생겼을 때 복구할 방법을 먼저 확보하세요.

워드프레스 · 이동 순서
  1. 관리자 → 플러그인
  2. 새로 추가 → 플러그인 업로드
  3. 내가 만든 플러그인 ZIP 선택
  4. 기존판 교체 여부 확인 → 설치·활성화
  5. 실제 글과 모바일에서 다시 확인
원본과 교체용 수정판을 함께 켜지 마세요기존 플러그인을 교체하는 수정판인지, 별도로 켜는 추가 플러그인인지 코덱스에게 먼저 확인하세요. 폴더 이름만 다르다고 함께 켤 수 있는 것은 아닙니다.
화면이 그대로거나 오류가 나면캐시와 활성화된 버전을 확인하세요. 오류가 나면 반복 설치하거나 초기화하지 말고, 수정판을 비활성화한 뒤 보관한 원본으로 복구합니다. 관리자 화면에 못 들어갈 경우를 대비해 호스팅 파일 복구 경로도 준비합니다.
오늘의 결과물받은 플러그인을 그대로 쓰는 데서 한 걸음 더 나아가, 내가 원하는 기능을 가진 작업본과 설치 파일을 만들었습니다. 실제 사이트 확인까지 마쳤는지 마지막으로 점검하세요.

막혔을 때

스킬이 안 보여요설치 위치와 스킬 이름을 확인해 달라고 하세요. 설치 파일이 있는데 발견되지 않으면 앱을 다시 시작하고 확인합니다.
ZIP을 못 읽어요선택한 작업 폴더 안에 실제 ZIP 파일이 있는지 확인하세요.
연습 사이트가 없어요5번 안내대로 준비 방법부터 묻습니다. 운영 사이트를 대신 연습장으로 쓰지 않습니다.
다른 곳도 바뀌었어요원하지 않은 부분을 정확히 말하고 해당 변경만 되돌려 달라고 하세요.
사이트 오류가 나요수정판을 비활성화하고 원본으로 복구합니다. 모르겠으면 오류 화면에서 비밀번호를 가리고 코치에게 보여주세요.
SEO 스킬이면 승인이나 노출이 보장되나요?아닙니다. 검색에 필요한 구조와 기존 기능을 확인하도록 돕는 지침입니다. 검색 순위·AI 답변 인용·애드센스 승인을 보장하지 않습니다.
강사·담당자용 검증 범위

스킬 다운로드·설치, 로컬 WordPress 실행·화면·복구, 검사 도구 시험을 확인했습니다. Windows 첫 설치, 첫 수강생 완주, 운영 사이트 적용은 별도 검증이 필요합니다. 설치 파일 확인과 실제 대화에서의 스킬 사용은 구분합니다.
