이전 버전 스킬이 이미 있다면

코덱스에게 기존 스킬의 위치와 개인 수정 여부를 확인해 달라고 하세요. 기존판을 보관한 뒤 새 버전으로 교체할 계획을 설명받고 진행합니다. 설치 문장을 반복해 기존판을 덮어쓰지 마세요.

스킬은 ‘코덱스의 작업 지침’입니다검색에 필요한 구조, 기존 기능 보호, 변경 후 확인 기준을 알려줍니다. 워드프레스에 설치하는 플러그인과는 다릅니다. 스킬 자체에는 별도 API 키가 필요하지 않습니다.
설치를 진행할지 물으면대상이 위 메킷 저장소인지 읽어보고 진행해라고 답하세요. 다른 도구 설치나 비용이 나오면 무엇이 필요한지 먼저 확인합니다.

확인할 것: 코덱스가 makeit-site-improve 스킬을 찾고 읽을 수 있어야 합니다.

내가 업그레이드할 것 고르기

세 가지 중 필요한 것 하나를 고르세요. 학생마다 같은 것을 고를 필요는 없습니다. 선택하면 아래 요청 문장이 바뀝니다.

어디를 개선할까요?

메킷 사이트 메이커로 이 폴더의 메킷애센을 업그레이드해줘. 기존 본문을 읽기 편하도록 글자 크기·줄 간격·문단 여백을 개선하고 싶어. 내 화면과 현재 소스부터 확인하고 플러그인에서 담당하는 부분만 작업본으로 고쳐줘. 바꾸기 전 화면을 남겨줘. 원본·글 내용·라이선스·광고·초기화 기능은 유지해줘. 새 사이트나 새 글, 별도 플러그인은 만들지 마. 테마나 서버 변경이 필요하면 먼저 설명해줘.

속도를 골랐다면 수정 전에 측정부터6번의 PageSpeed 안내를 먼저 보고 결과를 코덱스에 주세요. 점수만 보고 무작정 코드를 고치지 않습니다.

연습 사이트에서 직접 확인

같은 글을 수정 전과 후에 나란히 보세요. 글 내용은 그대로 두고 내가 고른 부분이 바뀌었는지, 컴퓨터와 휴대폰에서 모두 확인합니다.

  • 가독성: 글자·줄 간격·문단 여백이 원하는 대로인가요?
  • 모바일: 가로로 넘치거나 겹치는 부분이 없나요?
  • 기존 기능: 목차·카드의 링크가 여전히 맞는 곳으로 가나요?
  • 속도: 6번처럼 같은 조건에서 다시 측정했나요?
실제로 메킷애센을 바꾼 예시 보기

아래는 기존 관련 글 표시를 카드로 바꾼 실제 로컬 WordPress 시험입니다. 이것은 업그레이드 예시 하나이며, 모든 학생이 같은 카드로 만들 필요는 없습니다.

검증용 글·이미지를 사용한 화면입니다. 사진을 누르면 크게 볼 수 있습니다.

내가 선택한 메킷애센 개선을 연습용 WordPress에서 확인해줘. 같은 글·화면 크기로 전후를 보여주고, 글 내용 유지, 가독성, 모바일 넘침, 기존 목차·관련 글·링크·이미지·검색 관련 출력을 점검해줘. 속도를 바꿨다면 같은 조건의 측정 결과를 비교해줘. 확인하지 못한 것은 따로 알려줘. 운영 사이트에는 아직 적용하지 마.

연습 사이트가 아직 없다면운영 사이트를 건드리지 않고 연습할 환경을 준비하는 방법부터 알려줘라고 말하세요. 준비가 안 되면 화면 검증은 아직 끝난 것이 아닙니다.
“문법 검사 통과”만으로 끝이 아닙니다워드프레스에서 실제로 켜지고, 원하는 화면이 나오는지 확인해야 합니다.

내가 원하는 기능을 내가 정합니다. 아래 예시처럼 불편한 점과 원하는 결과를 말해보세요.

글자휴대폰에서 본문이 작아요. 내용은 그대로 두고 읽기 편하게 해줘.
목차기존 목차가 본문을 가려요. 휴대폰에서 겹치지 않게 해줘.
속도이 속도 검사 결과에서 메킷애센이 원인인 부분만 찾아줘.

이 입력란은 문장만 만듭니다. 복사해서 코덱스에 보내야 수정됩니다.

속도 실습 — PageSpeed Insights 사용하기

페이지스피드는 내 페이지의 속도와 개선할 곳을 보는 검사 도구입니다. 플러그인을 자동으로 고쳐주는 도구는 아닙니다.

PageSpeed Insights 열기 ↗
  1. 수정 전: 검사할 글 주소를 넣고 분석합니다. ‘모바일’ 결과와 측정 날짜를 보관합니다.
  2. 코덱스에 전달: 결과 링크 또는 캡처를 주고, 메킷애센에서 고칠 수 있는 원인을 찾게 합니다.
  3. 작업본 수정: 원인 하나만 고치고 연습 사이트의 화면·기능도 확인합니다.
  4. 수정 후: 같은 페이지·같은 조건에서 다시 검사합니다. 가능하면 전후 각각 3번 재고 가운데 값을 비교합니다.

성능 점수 — 모의 검사 종합 점수. 한 번의 숫자로 단정하지 않아요.

LCP — 큰 내용이 나타나는 시간. 보고서의 초 단위를 비교해요.

CLS — 화면 배치가 얼마나 흔들리는지 봐요.

메킷 사이트 메이커로 이 PageSpeed 결과와 내 메킷애센 소스를 함께 봐줘. 먼저 수정 전 수치와 측정 조건을 기록하고, 원인을 플러그인·테마·서버·이미지·외부 기능으로 나눠줘. 메킷애센 안에서 고칠 수 있는 항목 하나를 제안해줘. 아직 수정하지 말고 광고·통계·라이선스를 제거하는 방법은 제외해줘. 실제 방문자 자료와 모의 검사 결과를 섞지 마.

내 컴퓨터의 연습 사이트는 바로 검사할 수 없어요이 서비스가 접근할 수 있는 URL이 필요합니다. 로컬 환경은 코덱스에게 별도 로컬 검사 가능 여부를 물어보세요. 검사하려고 사이트를 무단 공개하거나 운영 사이트부터 바꾸지 않습니다. 서로 다른 사이트의 숫자를 전후 효과로 비교하지 마세요.

점수는 검사마다 달라질 수 있습니다. 실제 방문자 자료는 최근 28일 집계라 바로 바뀌지 않으며, ‘데이터 없음’은 0점이 아닙니다. Google의 측정 안내

현재 이 가이드에는 속도 향상 실측 사례를 싣지 않았습니다. 학생 자신의 페이지에서 측정한 값으로 판단합니다.

바꾼 뒤에는 한 번 더5번처럼 화면과 링크를 다시 확인하세요. 점수가 좋아도 글이 안 보이거나 기존 기능이 사라졌다면 성공이 아닙니다.

내 설치 ZIP과 복구 방법 받기

마음에 들고 검사도 끝났다면 워드프레스에 설치할 ZIP을 만들어 달라고 하세요.

확인한 작업본을 WordPress 설치용 ZIP으로 만들어줘. 원본은 덮어쓰지 마. 개인 키·비밀번호·수강생 설정 파일·DB·로그·백업은 넣지 말고, 기존 라이선스 기능은 유지해줘. 바꾼 내용, 검사 결과, 못 확인한 점, 원본으로 되돌리는 방법도 함께 정리해줘. 공개 배포는 하지 마.

받을 것은 네 가지내 수정본 ZIP · 변경 내용 · 검사 결과 · 이전 버전으로 돌아가는 방법.
‘초기화’는 되돌리기가 아닙니다초기화하면 글이나 설정이 지워질 수 있습니다. 원래대로 돌아갈 때는 보관한 원본과 백업을 사용합니다.
8

백업하고 내 워드프레스에 적용

연습 사이트에서 확인한 뒤 진행합니다. 운영 사이트의 파일·DB를 백업하고, 문제가 생겼을 때 복구할 방법을 먼저 확보하세요.

워드프레스 · 이동 순서
  1. 관리자 → 플러그인
  2. 새로 추가 → 플러그인 업로드
  3. 내가 만든 플러그인 ZIP 선택
  4. 기존판 교체 여부 확인 → 설치·활성화
  5. 실제 글과 모바일에서 다시 확인
원본과 교체용 수정판을 함께 켜지 마세요기존 플러그인을 교체하는 수정판인지, 별도로 켜는 추가 플러그인인지 코덱스에게 먼저 확인하세요. 폴더 이름만 다르다고 함께 켤 수 있는 것은 아닙니다.
화면이 그대로거나 오류가 나면캐시와 활성화된 버전을 확인하세요. 오류가 나면 반복 설치하거나 초기화하지 말고, 수정판을 비활성화한 뒤 보관한 원본으로 복구합니다. 관리자 화면에 못 들어갈 경우를 대비해 호스팅 파일 복구 경로도 준비합니다.
오늘의 결과물받은 플러그인을 그대로 쓰는 데서 한 걸음 더 나아가, 내가 원하는 기능을 가진 작업본과 설치 파일을 만들었습니다. 실제 사이트 확인까지 마쳤는지 마지막으로 점검하세요.
