실습 이미지는 실제 로컬 WordPress 캡처다. 글·그림은 검증용으로 작성했다.
시험 WordPress는 외부 HTTP·메일·자동 갱신·크론을 막고 로컬 주소에만 열었다. 운영 사이트는 연결하지 않았다.
메킷애센 프런트엔드 실습용 옵션은 시험 DB에서만 지정했다. 라이선스 서버 등록이나 전체 설정 마법사를 테스트한 것이 아니다.

## 변경의 의미
메킷애센에는 관련 글 목록과 별도 관련 글 영역이 함께 있었다. 개인 작업본에서는 두 영역을 카드 하나로 통합했다.
원래 목록의 같은 카테고리 우선·없으면 다른 최신 글 사용 기준을 재사용하고 비밀번호 글을 제외했다.
따라서 단순 색상 변경 외에 중복 영역 통합·표시 대상 보호가 포함된다. 라이선스·광고·초기화 기능을 수정하지 않았다.
원본과 수정판의 클래스·옵션 식별자는 같으므로 교체용이며 동시에 활성화하지 않는다.

## 아직 확인하지 않은 것
- 처음 보는 수강생·담당자의 실제 완주 시험.
- Windows 앱에서의 첫 설치·스킬 발견·대화 실행.
- 독립된 다른 Codex 대화에서의 자유 요청 행동 평가.
- MySQL/MariaDB, PHP 7.4, 다른 WordPress·테마·SEO 플러그인 조합.
- 운영 사이트 업로드 화면, 라이선스 등록, 전체 마법사, 광고 수익화.
- 검색 색인·순위·AI 인용·애드센스 심사 성과.
- 실제 사용자 Core Web Vitals. 이번 화면 검사는 성능 점수 시험이 아니다.

선언된 최소 PHP 버전과 실제 시험 버전은 다르다. 모든 환경 호환을 인증하지 않는다.
HTML 검사에서 noindex가 보인 것은 로컬 시험 사이트 설정이다. 스킬은 이를 자동으로 제거하지 않는다.
단위시험 통과는 스킬의 모든 판단이 올바르다는 보증이 아니다.

## 실행 방법
저장소 루트:
- `python3 -m unittest discover -s tests -v`
- `python3 skills/makeit-site-improve/scripts/site_check.py lint examples/makeit-related-lab`
- `python3 skills/makeit-site-improve/scripts/site_check.py html 저장페이지.html`

브라우저 시험은 기존 Playwright와 Chrome이 있는 개발 환경에서 수행했다. 패키지는 이 도구를 자동 설치하지 않는다.
`tests/browser-check.cjs`는 이번 로컬 시험 자료(주 글 5, 제외 글 11·12·13, 관련 공개 글 5개)를 대상으로 하는 회귀 검사다. 임의의 사이트 전체를 검사하는 도구가 아니다.
`tests/guide-check.cjs`는 첫 인수에 캡처 저장 폴더, 선택 두 번째 인수에 가이드 URL을 준다. 기본 URL은 로컬 8794 포트다.

## 공개·설치
GitHub 공개·원격 설치 결과는 공개 후 별도 기록한다. 현재 페이지의 체크박스는 학습 진행 기록일 뿐 자동 검증 결과가 아니다.

## 자동시험 설정
현재 GitHub 인증의 workflow 권한이 없어 Actions 워크플로는 적용하지 않았다. `ci-workflow.example.yml`은 참고 설정이며 실행된 CI가 아니다. 로컬 단위시험 결과와 구분한다. 권한을 갖춘 관리자가 검토 후 `.github/workflows/check.yml`로 배치할 수 있다.
