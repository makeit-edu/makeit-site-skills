# 공개 연습 예제
메킷애센 원본이 없는 사람도 작게 수정해 볼 수 있도록 새로 작성한 예제다.

1. 테스트 WordPress에 `makeit-related-lab` ZIP 설치·활성화.
2. 같은 카테고리의 공개 글을 2개 이상 준비. 대표 이미지는 선택.
3. 한 글의 “단축코드” 블록에 `[makeit_related_lab]` 입력.
4. 그 글에서 관련 카드·링크 확인. 기존 관련 글 자동 대체 기능은 아님.
5. Codex에게 색상·간격 등 원하는 변경 요청. 작업본 ZIP으로 재검증.

DB 설정·글 자동 생성·외부 API·추적 기능이 없다. 비활성화하면 단축코드 원문이 보일 수 있으므로 해당 단축코드 블록을 직접 제거하면 된다. 글·사진을 삭제하는 초기화 기능은 없다.

스킬과 이 플러그인은 서로 다른 설치 대상이다. 스킬 폴더는 Codex, 플러그인 ZIP은 WordPress에 설치한다.
