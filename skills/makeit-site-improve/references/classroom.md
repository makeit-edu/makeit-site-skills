# 메킷애센 수업 예제
수강생이 제공한 정식 플러그인 소스로 진행한다. 이 스킬에는 메킷애센 원본이 포함되지 않는다.
1·2주차 공통 자동화와 다른 작업 폴더를 사용한다.

첫 요청 예:
> 기존 관련 글을 사진 카드로 바꿔줘. 컴퓨터에서는 3열, 휴대폰에서는 1열. 원본은 보관하고 작업본만 수정해줘.

반드시 현재 버전의 훅과 렌더러를 찾아 실제 출력 경로를 추적한다. 일부 버전에는 관련 글 목록과 별도 관련 글 영역이 함께 있으므로 새 세 번째 영역을 만들지 않는다. 표시를 통합할 때 원래 연결하던 글이 누락되는지도 설명한다.
관련 글 수와 선택 기준을 바꾸는 것은 디자인 변경과 구분한다.
대표 이미지가 없는 글에 가짜 이미지 URL을 넣지 않는다. 대체 영역 또는 이미지 없는 카드를 사용한다.
라이선스·초기화·광고·홈페이지 생성 기능은 이 카드 실습의 수정 범위가 아니다.

학생 개인화 예:
- 간격·색·글자 크기 변경.
- 사진 없는 카드를 깔끔하게 정리.
- 작성자가 직접 입력한 요약 표시 기능 제작.

공개 연습 플러그인은 메킷애센 대체물이 아니다. 특정 글에 단축코드로 삽입하는 독립 연습물이며, 기존 관련 글 아래에 넣으면 두 영역이 나타날 수 있다.
